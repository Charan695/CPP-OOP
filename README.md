# C++ OOP Laboratory

Repository for 13 C++ Object-Oriented Programming experiments. Each experiment is organized in its own folder with a standalone C++ program.

## Build and run

Compile an experiment with a C++17 compiler:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o app
./app
```

## Experiments

1. C++ fundamentals: data types, constants, variables, operators and I/O
2. Classes, access specifiers and member functions
3. Constructors, destructors and Rule of 5
4. RAII with unique_ptr and shared_ptr
5. Single and multilevel inheritance
6. Runtime polymorphism and abstract Shape hierarchy
7. Function and operator overloading
8. Singleton design pattern
9. Templates: generic Stack
10. STL containers and algorithms
11. Custom exception hierarchy
12. CSV file I/O and file pointers
13. Student Portal mini project

Learning implementations. Review and understand each program before lab demonstration.
